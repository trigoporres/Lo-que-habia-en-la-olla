# Notas de los artículos

Un fichero por artículo, con el mismo nombre que el slug del post:
`notas/<slug>.md` para `src/content/articles/<slug>.mdx`.

Lo usa la skill `/revisar-notas` para contrastar el artículo con estas notas.
Apunta aquí fechas, nombres, cifras y fuentes tal como las tienes, incluidas
las dudas ("según unos... según otros...").
